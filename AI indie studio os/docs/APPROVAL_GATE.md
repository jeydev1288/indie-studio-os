# 승인 게이트의 범위

운영 배포, 유료 API·결제 변경, 운영 데이터 삭제, 외부 메시지, 민감 권한 변경은 루트 `AGENTS.md`의 사전 명시 승인 대상이다. 실제 행동은 구체적인 대상·변경·영향을 사용자에게 제시하고 사용자 승인을 받은 뒤 해당 플랫폼의 접근 제어와 승인 절차를 이용한다.

`python scripts/approval_demo.py deploy`는 격리된 **모의 실행기**다. 작업 유형을 보여주고 지정된 문자열을 입력할 때에만 모의 실행 메시지를 출력한다. 아무 외부 시스템에도 접속하거나 운영 작업을 실행하지 않는다. 입력은 파이프로도 공급할 수 있어 신원이나 실제 사용자 승인을 증명하지 못한다. 모의 승인 문자열은 실제 작업의 승인으로 사용할 수 없다.

직접 CLI, 다른 스크립트, 앱 커넥터를 호출하면 이 데모를 거치지 않는다. 따라서 이 데모는 실제 배포·결제·삭제·메시지·권한 변경을 기술적으로 보호하지 못한다. 향후 실사용 자동화는 대상 플랫폼의 인증된 사용자 승인, 작업별 범위·대상·만료·감사 및 우회 방지를 해당 실제 실행 경로에 연결하고 별도 시험해야 한다. 현재 Git 저장소, CI/CD 또는 실제 운영 실행기가 없어 그런 강제 기능은 구성하지 않았다.
