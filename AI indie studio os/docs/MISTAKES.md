# 오류 기록

재현과 수정이 확인된 오류만 여기에 기록한다. 미확인 증상과 원인 가설은 별도로 표시하며 확인 전 교훈을 공통 규칙으로 승격하지 않는다.

기존 오류와 검증 내역은 [에이전트 오답노트](../learning/mistakes.md)에 보존되어 있다. 해당 기록은 인코딩 문제와 수정 후 검사 결과를 포함하지만 재현 절차가 충분히 기록되어 있지 않아 이 문서에 검증 완료 사례로 옮기지 않는다.

새 기록: 날짜 · 영향 · 재현 조건과 증거 · 확인된 원인 · 수정 · 회귀 검증 결과 · 교훈과 매뉴얼 반영 여부.

## 2026-11-06: 격리된 누락 출처 테스트

- 영향: Phase 4 테스트용 임시 JSON만 영향받음. 운영 데이터에는 적용하지 않았다.
- 재현: 임시 파일에 `{"idea":"sample"}`만 넣고 `source_url` 필수 검사를 실행해 `ValueError: source_url missing`을 확인했다.
- 원인: 테스트 픽스처에 필수 출처 필드가 없었다. 이는 의도적으로 만든 결함이다.
- 수정 및 재검증: 픽스처에 `https://example.com/evidence`를 추가하고 같은 검사에 통과했다. 해당 URL은 가짜 테스트 데이터이며 실제 시장 근거가 아니다.
- 교훈: 누락된 출처는 근거가 있는 자료로 보완하거나 미확인으로 남겨야 한다. 이번 검사는 필드 존재만 확인했으며 URL의 진위·주장 적합성은 검증하지 못했다. 단일 모의 사례이므로 매뉴얼 공통 규칙으로 승격하지 않았다.
