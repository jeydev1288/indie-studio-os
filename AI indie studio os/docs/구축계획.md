# 구축 계획과 환경

2026-11-06 기준 작업 디렉터리에 기존 `docsSTUDIO_MASTER_PLAN.md`가 있었고 Git 저장소는 없었다. 설치된 CLI는 `codex-cli 0.166.0-alpha.6`이며, 현재 세션에는 병렬 하위 에이전트 도구가 있다. 개별 세션의 도구·권한·설정은 달라질 수 있다.

## 계획

1. 기존 파일과 Codex 기능을 확인하고 기존 마스터 계획을 보존한다.
2. 루트 규칙, 매뉴얼, 상태·학습 기록을 작성한다.
3. 지원되는 프로젝트별 에이전트 설정과 목적이 명확한 스킬을 구성한다.
4. SaaS 10개 조사 절차와 비교 양식을 준비한다. 실제 시장 조사는 별도 실행이며 결과를 미리 채우지 않는다.
5. 설정 파싱과 가능한 범위의 발견·시나리오 검증을 실행하고 근거와 한계를 기록한다.

## 선택과 한계

Markdown은 읽고 수정하기 쉽고 별도 운영비가 없지만 동시 수정 충돌, 자동 상태 동기화, 강제 승인 기능이 없다. V1은 Codex의 세션 내 오케스트레이션과 수동으로 유지하는 기록을 사용한다. 제품 저장소, 스케줄러, 데이터베이스, 배포 시스템을 새로 만들지 않는다. 외부 시스템을 연결할 때는 별도 권한과 검증이 필요하다.
