# 에이전트 오답노트

## 2026-11-06: Windows PowerShell 파일 인코딩

- 증상과 근거: 최초 생성된 에이전트 설명에 한글 깨짐이 발생했으며 Python으로 파일 내용을 읽어 확인했다.
- 원인: Windows PowerShell 5가 BOM 없는 UTF-8 스크립트를 시스템 인코딩으로 해석한 것으로 판단했다.
- 조치: PowerShell 7로 UTF-8 스크립트를 다시 실행했다.
- 검증: 5개 TOML을 UTF-8로 읽어 파싱하고 각 설명의 한글을 확인했다. 두 스킬의 UTF-8 구조도 검사했다.
- 상태: 수정됨. 다른 모든 문자에 대한 완전한 검증은 아니다.
- 교훈: UTF-8 스크립트 실행 시 셸 버전과 인코딩을 확인한다. 재사용 범위를 더 검토하기 전 공통 운영 규칙으로 승격하지 않는다.
